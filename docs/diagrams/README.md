# Diagram sources

Every diagram in the project is stored here as Mermaid code. GitHub renders `.mmd` files directly, and each one is also embedded in the document it belongs to.

| File | Diagram | Appears in |
|---|---|---|
| `00-use-case.mmd` | Use case diagram | Milestone 2 SRS, section 6.1 |
| `00-user-journey-import.mmd` | Statement import journey with AI confidence check | Milestone 2 SRS, section 6.2 |
| `01-container.mmd` | Container diagram | Milestone 3 design, section 4 |
| `02-class.mmd` | Class diagram | Milestone 3 design, section 5.1 |
| `03-state.mmd` | Transaction state diagram | Milestone 3 design, section 5.2 |
| `04-sequence-import.mmd` | Sequence: import a statement | Milestone 3 design, section 6.1 |
| `05-sequence-manual-entry.mmd` | Sequence: add a manual transaction | Milestone 3 design, section 6.2 |
| `06-sequence-report.mmd` | Sequence: view a month report | Milestone 3 design, section 6.3 |
| `07-sequence-ai-fallback-override.mmd` | Sequence: low confidence fallback and override | Milestone 3 design, section 6.4 |
| `08-erd.mmd` | Entity relationship diagram | Milestone 3 design, section 7 |
| `09-deployment.mmd` | CI and deployment pipeline | Milestone 3 design, section 8 |
| `10-ai-pipeline.mmd` | Categorization pipeline | Milestone 3 design, section 9 |

When a diagram changes, update the embedded copy in its document and the file here in the same commit.
